# Keywords Tracker — Weekly Rank Monitoring

Track keyword ranks per locale. Update mỗi thứ Hai sau launch.

## Update workflow

1. Play Console → Statistics → Acquisition reports → Search terms (per locale, per week)
2. For tracked keyword, note rank. If > 200, mark as "not ranked" (NR).
3. After 4 weeks: drop keywords stuck at NR, replace với new long-tail từ Search Terms report.

## ⭐ Pure-phonics keyword priorities (lowest comp, highest brand fit)

These are the easiest wins — track aggressively:
- 🇻🇳 `phonics cho bé`, `phonics tiếng anh`, `app phonics trẻ em`
- 🇮🇩 `phonics anak`
- 🇹🇭 `phonics เด็ก`
- 🇧🇷 `phonics crianças`
- 🇲🇽 `phonics niños`
- 🇯🇵 `フォニックス 子供`
- 🇰🇷 `파닉스 어린이`
- 🇹🇷 `çocuk phonics`

If any of these are NR after 14 days, troubleshoot:
1. Check long description has keyword 3+ times (TF-IDF threshold)
2. Check short description references "phonics" + locale word for "kids"
3. Check first screenshot text overlay includes keyword
4. If still NR after 30 days → competitor brand may be cannibalizing → switch to long-tail `học phonics tiếng anh miễn phí` style
